# «Завалинка»: исправленная карта ветвления

Этот документ фиксирует текущую authoring-модель ветвления первой истории после проверки причинно-следственной логики и признаков машинно-сгенерированного текста.

Он не является вторым runtime. Исполняемым источником после реализации остаётся `stories/zavalinka/story.ink`. При конфликте приоритет: логика мира и исходная история → качество выбора → эта карта.

## Общие правила

- Никаких случайных процентов: одинаковое состояние и одинаковый выбор дают одинаковый результат.
- Позднее решение не отменяет раннюю ошибку.
- Предмет появляется только там, где его физически можно найти.
- Не каждая бытовая деталь обязана становиться предметом, флагом или foreshadowing.
- Быстрый живой заражённый реагирует на движение и звук; мертвецы медленные, но опасны массой.
- Ливень глушит шаги и часть шума, поэтому сюжетный шум должен иметь конкретный физический источник.
- Косметические choices без последствий не добавляются.
- Канонический трагический маршрут исходной «Завалинки» должен оставаться проходимым.

## Состояние

Начальные значения:

```text
HAMMER = false
ROPE = false
KNIFE_AVAILABLE = true
PIPE_KNOWN = false
ATTIC_KNOWN = false
HATCH_OPEN = false
BARRICADE = false
BLACKOUT = false
TOOLS_READY = false
WINDOW_READY = false
WINDOW_SECURED = false
ILYA_RESTED = false
BITE_ILYA = false
BITE_LERA = false
ILYA_BITE_KNOWN_TO_LERA = false
LERA_BITE_KNOWN_TO_ILYA = false
ILYA_ALIVE = true
LERA_ALIVE = true
```

`PREP_ACTIONS_LEFT` устанавливается после осмотра дома.

## 1. Посёлок

### D1. Возвращаться к уже пропущенным домам

Игрок выбирает один вариант:

- идти прямо к дому с целыми окнами;
- осмотреть крыльцо с кровью;
- коротко проверить дом с открытой задней дверью → `HAMMER = true`;
- заглянуть в дом с выбитыми окнами → `ROPE = true`.

Молоток и верёвка не получают фиктивных «цен», если эти последствия дальше нигде не учитываются. Шум посуды, мокрая одежда и другие мелочи могут оставаться частью сцены, но не должны изображаться как механика без реального позднего эффекта.

## 2. Дом снаружи

### D2. Перед входом

Оставить два осмысленных варианта:

- войти сразу;
- обойти дом → `PIPE_KNOWN = true`, герой замечает жёлтую газовую трубу и маленькое чердачное окно.

Вариант «пять минут слушать», который не менял состояние и не открывал новой информации, удалён.

## 3. Осмотр дома

### D3. Глубина проверки

**Обычный осмотр**: шкафы, пространство под кроватью, занавески, санузел.

```text
ATTIC_KNOWN = false
PREP_ACTIONS_LEFT = 3
```

**Полный осмотр**: дополнительно потолок, печь и пространство над шкафами.

```text
ATTIC_KNOWN = true
PREP_ACTIONS_LEFT = 2
```

Полный осмотр больше не является бесплатным строго лучшим выбором: найденный заранее люк оплачивается временем, которое иначе можно было потратить на подготовку.

## 4. Подготовка перед сном

Пока `PREP_ACTIONS_LEFT > 0`, можно выбирать разные действия. Каждое действие уменьшает счётчик на 1; повтор одного и того же действия недоступен.

Доступные действия:

- укрепить вход → `BARRICADE = true`;
- закрыть окна без щелей → `BLACKOUT = true`;
- подготовить доску и инструменты → `TOOLS_READY = true`;
- дать Илье коротко поспать → `ILYA_RESTED = true`;
- найти/сорвать с краски люк → `ATTIC_KNOWN = true`, `HATCH_OPEN = true`;
- при `HATCH_OPEN = true` подготовить чердачное окно → `PIPE_KNOWN = true`, `WINDOW_READY = true`.

Ужин больше не конкурирует с полезными действиями. После `PREP_ACTIONS_LEFT = 0` Илья и Лера обязательно едят и немного согреваются, затем начинается ночное дежурство. Ужин не создаёт отдельного gameplay-флага.

Канонический маршрут исходной истории: укрепить вход + закрыть окна → ужин → Илья дежурит без предварительного сна.

## 5. Ночь

### D4. Кто дежурит после подготовки

- Илья: при `ILYA_RESTED = true` получает раннее предупреждение; иначе засыпает и получает позднее предупреждение.
- Лера: раннее предупреждение.
- оба спят: позднее предупреждение.

### Раннее предупреждение

Игрок может погасить свет и не подходить к окнам, идти к заранее найденному люку, посмотреть наружу или слушать у стены.

Если `BLACKOUT = true` и никто не выдаёт движение у окна, заражённый не получает зрительного подтверждения и может уйти → E1.

Уход к люку доступен только при `ATTIC_KNOWN = true`.

### Позднее предупреждение

В канонической ветке Илья смотрит через щель, заражённый замечает движение, кричит и начинается штурм.

Ранний уход на чердак также вызывает штурм, но причина теперь физическая: скрипит кровать, отзываются половицы, крышка люка проходит по старой краске. `HATCH_OPEN + BARRICADE` позволяют обоим подняться до первого пролома; без одного из условий времени не хватает.

## 6. Штурм

### D7. До первого пролома

- идти к люку, если он известен;
- встретить быстрого заражённого у первой комнаты;
- пытаться уйти через террасу → E9.

Отдельного действия «ещё раз подвигать мебель ради +времени» нет: `BARRICADE`, `TOOLS_READY` и `HAMMER` должны влиять только там, где их физическая роль понятна.

### Первый быстрый заражённый и нож

Нож входит выше ключицы и застревает. С этого момента состояние ножа фиксируется явно.

### D8. Нож застрял

- бросить нож и оторваться → `KNIFE_AVAILABLE = false`;
- выдернуть нож → `KNIFE_AVAILABLE = true`, `BITE_ILYA = true`; Лера момента укуса не видит;
- при `TOOLS_READY` попросить Леру ударить доской → Илья отрывается, нож остаётся в заражённом → `KNIFE_AVAILABLE = false`;
- удерживать заражённого, пока Лера готовит подъём → `KNIFE_AVAILABLE = false`.

## 7. Подъём на чердак

### D9. Кто лезет первым

Только два choices:

- Лера первой;
- Илья первым.

`ROPE` не является третьим «порядком подъёма». Если верёвка есть, она автоматически доступна как страховка/петля в соответствующей ветке.

### Лера первой

Если `BARRICADE && HATCH_OPEN`, Илья успевает подняться следом.

Иначе его хватают за ноги и кусают:

```text
BITE_ILYA = true
ILYA_BITE_KNOWN_TO_LERA = true
```

Дальше:

- тянуть до разрыва рукава → Илья остаётся внизу;
- отпустить после укуса → Илья остаётся внизу;
- спрыгнуть к нему → E11;
- при `ROPE = true` получить ещё одну попытку и вытянуть Илью; верёвка после подъёма остаётся у героев.

### Илья первым

`ROPE` или `HATCH_OPEN` дают больше времени.

Если `KNIFE_AVAILABLE = true` или `TOOLS_READY = true`, Илья может сначала отбить заражённого сверху и вытащить Леру без нового укуса.

Если он сразу рвёт Леру вверх, заражённый успевает укусить её:

```text
BITE_LERA = true
LERA_BITE_KNOWN_TO_ILYA = true
```

Если Илья уже был укушен, это допустимое состояние двух укусов; оно не схлопывается в ветку «один укушен».

Если времени и средств удержать Леру нет, `LERA_ALIVE = false`, Илья остаётся на чердаке один.

## 8. Чердачное окно

Если `PIPE_KNOWN = true`, герой заранее понимает путь заражённого по газовой трубе и получает D11A до прямого контакта.

Если `PIPE_KNOWN = false`, сцена идёт по канонической последовательности: пальцы на раме → первый удар → второй → трещина → третий удар.

### D11A. До контакта

- заранее заблокировать окно; `WINDOW_READY` ускоряет действие → `WINDOW_SECURED = true`;
- заранее искать выход через обшивку крыши;
- открыть люк вниз → E10;
- сознательно ждать заражённого у окна → каноническая сцена контакта.

### D11B. После третьего удара

- блокировать окно: гарантированно успеть можно при `WINDOW_READY` или `TOOLS_READY`, затем `WINDOW_SECURED = true`;
- сбить пальцы доской и закрыть окно → `WINDOW_SECURED = true`;
- вскрывать крышу напрямую: после третьего удара успеть можно только с `HAMMER`;
- открыть люк вниз → E10;
- промедлить/бездействовать → E12.

## 9. Выход через крышу

Выход находится не в абстрактной «дырке в крыше». На противоположном от газовой трубы скате изнутри видна старая дощатая обшивка; одна доска держится на ржавых гвоздях и уже отошла от стропила.

- ранний поиск слабого места возможен при `PIPE_KNOWN`;
- `HAMMER` позволяет быстро поддеть и вытащить гвозди после начала разрушения окна;
- без этих преимуществ после третьего удара сначала нужно защитить окно.

### D12. Спуск

- `ROPE = true` → O1: спуск по верёвке;
- `ROPE = false` → O2: спуск к низкому краю и прыжок в размокшую землю;
- остаться до рассвета → E7 только при `WINDOW_SECURED = true`.

Декоративная обязательная травма после прыжка удалена: если травма не меняет дальнейшую ветку, она не нужна как псевдопоследствие.

## 10. Состояние после побега

После O1/O2 сначала проверяется, кто жив, затем укусы.

```text
оба живы, укусов нет       -> E15
оба живы, один укус        -> D13
оба живы, два укуса        -> E17
ILYA_ALIVE = false         -> O3 -> E16
LERA_ALIVE = false         -> O4 -> E16
```

### D13. Укушен ровно один

- сказать об укусе → E4;
- разойтись → E5;
- скрыть укус → E6, только если второй не видел именно этот укус.

Для скрытого укуса используются направленные состояния знания:

```text
ILYA_BITE_KNOWN_TO_LERA
LERA_BITE_KNOWN_TO_ILYA
```

## Terminal endings

- **E1 — Тихое утро:** штурм не начался; оба уходят к трассе.
- **E4 — К трассе с укусом:** один укушен и признаётся; если оружие сохранилось, его несёт здоровый.
- **E5 — Разойтись:** укушенный остаётся у окраины, второй идёт к трассе.
- **E6 — Скрытый укус:** один скрывает рану, второй продолжает путь, не зная об укусе.
- **E7 — Дом держит до рассвета:** путь быстрого заражённого наверх перекрыт, герой/герои ждут света.
- **E9 — Терраса:** попытка открыть заблокированный выход впускает толпу.
- **E10 — Вниз:** люк открывают в заполненный заражёнными дом.
- **E11 — Не отпустила:** Лера возвращается вниз к Илье; оба погибают.
- **E12 — Стекло:** окно не успевают защитить; быстрый заражённый попадает на чердак.
- **E15 — К станции вдвоём:** оба живы, укусов нет.
- **E16 — К станции одному:** второй персонаж погиб в доме.
- **E17 — Два укуса:** оба живы и оба укушены; после проверки ран идут к станции вместе, потому что другого направления у них нет.

O1–O5 остаются промежуточными состояниями, а не endings.

## Требования к production prose

Техническая карта намеренно использует флаги, списки и симметричные проверки. Художественный текст не должен копировать её язык.

- Не показывать читателю имена флагов, `D*`, `O*` и `E*`.
- Не объяснять последствия формулами «это не X, а Y» там, где их можно показать действием.
- Не делать каждую найденную вещь обязательной будущей механикой; сохранить бытовые детали без payoff.
- Причины действий должны быть физическими: конкретный звук, расстояние, мебель, положение тела, мокрые поверхности.
- E4/E5/E6 писать по-разному в зависимости от того, кто укушен; одинаковое состояние не означает одинаковую сцену для Ильи и Леры.
- Не завершать ветки универсальными зловещими афоризмами. Финал должен опираться на действие, предмет или конкретное решение персонажа.
- Сохранять географию дома и телесные ограничения: кто где находится, за что держится, что мешает двигаться.

Перед финальным литературным проходом отдельно проверить текст по `template/признаки ии/ai_text_signs_full_511.md`, но не «лечить» техническую документацию искусственной разговорностью или намеренными ошибками.
