## Возраст и маркировка контента

Для текущего текстового содержания предлагается **12+**:

- история относится к хоррору и содержит пугающие ситуации;
- присутствуют описания крови, заражённых, угрозы насилия, укусов и смертей персонажей;
- текущий формат — текстовый, без реалистичных графических сцен жестокости.

Маркировки:

- **Жестокость** — из-за описаний физического насилия, угрозы и смертей;
- **Страх** — из-за хоррор-сцен, заражённых и ситуаций, рассчитанных на напряжение/страх.

Перед отправкой на модерацию перечитать финальную compiled story. Если итоговая проза станет заметно более графичной или жестокой, возрастную категорию нужно пересмотреть, а не сохранять 12+ автоматически.

## Иконка

Launcher icon уже подключена в Android manifest как `@mipmap/ic_launcher` и присутствует во всех density-каталогах.

Для RuStore нужен отдельный upload-файл 512×512. Сгенерировать технический export того же изображения:

```powershell
.\scripts\export-rustore-icon.ps1
```

Результат:

```text
dist/rustore/icon-512.png
```

Скрипт создаёт непрозрачный PNG 512×512 из текущей launcher icon. Если есть исходник этой же иконки в 512×512 или больше, предпочтительнее передать его через `-SourcePath`, чтобы не увеличивать 192×192 launcher asset.

Перед публикацией вручную проверить:

- визуально это та же иконка, что установлена на устройстве;
- по краям нет прозрачных областей;
- мелкие детали читаются в уменьшенном виде;
- файл не содержит текста/элементов, которых нет в установленной иконке.

## Скриншоты

Минимум для RuStore — три актуальных скриншота одной ориентации. Для первой карточки подготовить четыре вертикальных 9:16:

| Файл | Что показать |
| --- | --- |
| `01_catalog.png` | Каталог историй с карточкой «Завалинка» |
| `02_reader_choice.png` | Реальный экран чтения: текст и доступные варианты выбора |
| `03_settings.png` | Настройки режима чтения/темы |
| `04_ending.png` | Финальный экран или список уже открытых концовок |

Правила для набора:

- только интерфейс текущего release build `v0.4.0`;
- без Android status/navigation bars и интерфейса других приложений;
- без видимой рекламы Yandex или других сторонних сервисов;
- без debug/Metro overlays;
- текст на русском;
- одинаковая ориентация и пропорция 9:16;
- не показывать функции, отсутствующие в релизе;
- не использовать старые mockups из `docs/ui/mockups/v0.1.8` как store screenshots.

Снимок сохраняется командой:

```powershell
.\scripts\capture-rustore-screenshot.ps1 -Name 01_catalog
```

Helper сохраняет исходный кадр в `dist/rustore/screenshots/raw/`, а готовый файл — в `dist/rustore/screenshots/`. Если экран телефона имеет вытянутую пропорцию вроде 1080×2400 (20:9), итоговый файл автоматически обрезается по центру до поддерживаемой вертикальной пропорции 9:16 (для 1080 px по ширине — 1080×1920). Исходник остаётся рядом для повторного кадрирования.

После автоматического crop обязательно открыть готовый файл и проверить, что текст, варианты выбора и другие важные элементы не попали за границы кадра.

3. Убедиться, что launcher/store icon визуально совпадают.
4. Убедиться, что загружено минимум три актуальных скриншота одной ориентации.
5. Проверить, что на скриншотах нет сторонней рекламы и Android UI.
6. Проверить краткое и полное описания на соответствие текущей функциональности.
7. Повторно проверить возрастную категорию и маркировки по финальному тексту «Завалинки».
8. Проверить доступность публичной privacy policy.
9. Просмотреть превью карточки в RuStore после автоматического кадрирования и до отправки на модерацию.
