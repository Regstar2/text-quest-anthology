# Карта решений «Завалинка»

`zavalinka-decision-map-v4.canvas` — рабочая карта ветвления истории для Obsidian Canvas.

## Что исправлено в v4

- ветка D8, где Илья удерживает заражённого и отправляет Леру к люку, теперь фиксирует Леру первой и не позволяет затем выбрать Илью первым;
- состояние люка разделено по смыслу: `HATCH_PREPARED` означает заранее освобождённую от краски, но закрытую крышку; фактическое открытие происходит только во время подъёма;
- баррикада больше не «задерживает разбивание окна»: она влияет только на продвижение заражённого внутри дома после пролома;
- ветка без `BLACKOUT` получила определённую причинность обнаружения вместо формулировки «мог заметить» при гарантированном штурме;
- удалены неиспользуемые состояния `SIEGE` и `LERA_BITE_KNOWN_TO_ILYA`;
- верёвка заменена на толстую хозяйственную, пригодную для страховки и спуска;
- спуск без верёвки привязан к низкому скату над пристройкой, чтобы избежать необъяснимого безопасного прыжка с высоты;
- вывод по кровавому следу ослаблен: он указывает на вероятный выход из дома, но не доказывает дальнейший маршрут;
- рискованные варианты через террасу, вниз через люк и попытка вернуться за Ильёй сформулированы как решения в условиях неполной информации, а не очевидные кнопки смерти;
- ожидание рассвета на чердаке стало промежуточным исходом O6 и продолжает маршрут через противоположный фронтон;
- удалены пустые изолированные узлы;
- уточнена легенда исходного маршрута;
- добавлена минимальная персонажная причинность для привычки Ильи скрывать состояние и решения скрыть укус.

## Важно

Флаги и счётчики — внутренняя модель ветвления. В пользовательском тексте они не должны показываться буквально: состояние выражается через действия, предметы, знания персонажей и последствия предыдущих решений.

Текущий `stories/zavalinka/story.ink` этим изменением не затрагивается. Полная карта должна переноситься в Ink отдельным этапом после утверждения ветвления.
